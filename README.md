# CPK Ingeniería — Institucional R02

Actualizado al 15/10/2026.

Subir el contenido del ZIP a la raíz del repositorio: index.html, assets/, documents/ y .nojekyll. En Settings → Pages: Deploy from a branch → main → /(root) → Save. No subir el ZIP como archivo.

Los PDF se abren en un visor dentro de la página y se pueden descargar. El archivo HTML portátil entregado por separado incluye imágenes y PDFs para uso sin conexión.

Se conservan temperaturas y escalas de los termogramas originales. La fundación del silo se identifica como representación de anteproyecto.
